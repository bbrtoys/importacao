# Pedido de Importação

Sistema de cadastro de pedidos de importação: login, tela de novo pedido, painel de pedidos e cadastro de usuários e clientes.

- `index.html`: o sistema (publicado pelo GitHub Pages).
- `banco.sql`: estrutura do banco no Supabase (tabelas, regras de acesso e clientes iniciais). Já foi executado no projeto; fica aqui como registro.
