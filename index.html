Como os indicadores são calculados
Só entram os produtos do catálogo importado, somados pelo código. O mínimo para importação é o MOQ da planilha; MOQ em branco conta como sem mínimo. “Itens no catálogo” considera o catálogo completo; os demais indicadores acompanham os filtros. Os valores são estimados pelo preço do catálogo.
